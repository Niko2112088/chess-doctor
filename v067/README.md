# Chess Doctor v0.6.7 Beta

Move-role labels for guided visual lessons.

## What changed

The guided lesson now makes the purpose of every visual scene explicit before the piece moves.

Role badges:
- **ПОЗИЦИЯ ДО ХОДА**
- **ТВОЙ ХОД**
- **ПОСЛЕ ТВОЕГО ХОДА**
- **ХОД СОПЕРНИКА**
- **СИЛЬНЫЙ ХОД**

Each role has a distinct visual treatment so a beginner can tell whether Doctor is showing their move, the opponent's reply, or the recommended move without relying on the board animation alone.

No chess-analysis logic changed.
