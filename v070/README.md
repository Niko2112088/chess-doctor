# Chess Doctor v0.7.0 Beta

Full chess-piece redesign.

The entire custom SVG set has been replaced so every piece now belongs to one visual system inspired by the approved reference sheet:

- consistent outline weight;
- consistent pedestal/base treatment;
- cleaner small-screen proportions;
- pawn, rook, bishop, knight, queen and king all redrawn;
- knight now uses a clearly horse-like profile with muzzle, eye, nostril and mane marks;
- bishop remains visually distinct from the pawn;
- white and black versions use the same silhouettes.

All v0.6.9 animation and chess-analysis behavior is preserved.
