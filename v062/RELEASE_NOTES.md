# Chess Doctor v0.6.2 RC

Mobile UX patch from real iPhone Safari acceptance.

## Fixed
- Removed source-piece spoilers from Master Guess before the learner selects a piece.
- Legal destination hints now appear only after a piece is selected.
- Added clearer feedback for opponent pieces, immobile pieces, check-response constraints, deselection and switching pieces.
- Redrew the knight as a larger, more recognisable horse-head silhouette on small screens.

No analysis/evaluation logic changed. v0.6.1 remains preserved at `/v061/`.
