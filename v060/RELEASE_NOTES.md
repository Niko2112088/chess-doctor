# v0.6.0 RC — Learning Edition

- Two top-level learning paths with the same board and evaluation truth layer.
- 25 famous historical games (1858–2018), Russian names, themes and era filters;
  complete legal replay, source manifests, factual data only.
- Master Lesson: immediate guided replay, plain Russian moves, optional notation,
  confirmed key moments, player sides, turn indication, board rotation.
- Guess the Move: legal board interaction, promotion choice, exact / strong /
  playable / weaker feedback, actual-attempt explanation and reveal action.
- Shared two-pass scanner, equal-depth pair comparisons, legal recommendations,
  normalized White POV and explicit terminal positions.
- Lazy local Worker, reusable session caches, progress, stop/restart and
  cancellation guards against stale game/mode/attempt results.
- My Game retains Doctor, Try Again and Detective; grammar and pluralization
  fixes, accessible coordinates, page zoom and 44px non-board controls.
- Regression matrix for v050/v060, data / lesson / guess tests and a real Chromium
  browser job exercising assets under `/chess-doctor/v060/`.

No public candidate promotion; v050 and historical/root app files are unchanged.
See QA.md for evidence, known limitations and the iPhone acceptance checklist.
