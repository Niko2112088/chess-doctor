# Chess Doctor v0.6.3 RC

Small visual/information polish from real iPhone Safari feedback.

## Changed
- Knight SVG uses a cleaner, more classic horse-head silhouette for recognition on small boards.
- Master Lesson header shows total game length in full chess moves, e.g. `1858 · Paris · Победили белые · 17 ходов`.
- Replay progress no longer calls plies "ходы"; it uses natural text such as `После 15-го хода чёрных`.

No chess analysis logic changed. v0.6.2 remains preserved at `/v062/`.
