# Chess Doctor v0.7.1 Beta

Piece proportions and alignment pass.

This build keeps the v0.7.0 unified piece style but corrects the relative scale of the set and adopts the simpler classic knight silhouette chosen by the user.

Visual hierarchy:
- pawn — smallest;
- rook — larger than pawn, still compact;
- bishop — slightly taller;
- knight — larger, but no longer oversized;
- queen and king — same major-piece scale.

All pieces now sit on a consistent lower baseline inside each square so the bases visually align across a rank.

No chess-analysis or animation logic changed.
